# Salles Horizon

Site statique responsive, sans installation ni dépendance.

## Déploiement GitHub + Cloudflare Pages
1. Créer un dépôt GitHub.
2. Déposer `index.html` et le dossier `plans` à la racine du dépôt.
3. Dans Cloudflare Pages, connecter le dépôt.
4. Sélectionner un projet sans framework.
5. Laisser la commande de build vide et choisir `/` comme répertoire de sortie.

Les coordonnées des salles sont approximatives et doivent être vérifiées sur site.
