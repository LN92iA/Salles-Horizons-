# Salles Horizon V3

Version statique responsive basée sur l'image haute résolution fournie.

## Publication GitHub + Cloudflare Pages
1. Décompresser le ZIP.
2. Remplacer dans le dépôt GitHub existant `index.html` et l'ancien dossier `plans` par ceux de ce ZIP.
3. Conserver `index.html` et `plans` à la racine du dépôt.
4. Valider le commit. Cloudflare Pages republiera le site.

Aucune commande de build n'est nécessaire.
